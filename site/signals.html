What each signal means

Model pick — the EPA power-rating model's predicted spread vs. the market's. Shown as the team the model thinks will beat the market's line, with the edge in points. A muted "lean" badge means the edge is under the model's own 2.0-point flag threshold — still the model's direction, just not a game it would flag as a pick. This model's confidence is not reliably calibrated (see Games for the full track record).

Big home dog rule — only appears when the home team is getting 7+ points. Tested directly against history (not part of the model): home dogs of that size have covered 54–56% ATS across two different sample windows since 1999. Real signal, but adding it into the model's own regression made the model's picks worse, not better — so it's tracked here as an independent, standalone rule instead. See HANDOFF.md for the full test.

Not shown: fatigue (tested — travel, short rest, consecutive road games, coming off overtime — none showed a real edge) and expert consensus (no historical dataset exists to test it against, so it can't be shown here as a "does this hold up" signal). Showing either would imply they're proven when they aren't.
